# 官方API

> 整理自哔哩哔哩直播开放平台《开放平台-直播&互玩接入文档》。原文：[应用 API](https://open-live.bilibili.com/document/eba8e2e1-847d-e908-2e5c-7a1ec7d9266f)。
>
> 项目开启、关闭、心跳与批量心跳。直播桥用身份码换取一场 `game_id` 和官方长连接信息。

**注意**
请严格确保游戏生命周期内可以按下图流程与开放平台进行交互，否则将会视为项目是有缺陷的！这将会影响到后续的审核，以及您后续的收益！此外请注意调用API时返回的公共错误码，对具体的错误码要进行相关逻辑处理。

## 项目开启

- 接口描述：开启项目第一步，平台会根据入参进行鉴权校验。鉴权通过后，返回长连信息、场次信息和主播信息。开发者拿到长连和心跳信息后，需要参照[长连说明](websocket-protocol.md)和[项目心跳](#项目心跳)，与平台保持长连。
- 接口地址：/v2/app/start
- 方法：POST
- 请求头：需要
- 请求参数：

| 参数名 | 必选 | 类型 | 描述 |
| --- | --- | --- | --- |
| code | 是 | string | [主播身份码](https://open-live.bilibili.com/document/5dffc297-6fd2-41ff-bd45-6e8b89e2a68e) |
| app_id | 是 | int64 (超过int32长度的数值，注意不要用普通int，会溢出的) | 项目ID |

**响应**：

```json
{
    "code": 0,
    "message": "ok",
    "data": {
        //  场次信息
        "game_info": {
            //  场次id,心跳key(推荐心跳保持20s)调用一次,互动玩法超过60秒，H5插件和工具超过180s无心跳自动关闭,长连停止推送消息
            "game_id": ""
        },
        //  长连信息
        "websocket_info": {
            //  长连使用的请求json体 第三方无需关注内容,建立长连时使用即可
            "auth_body": "",
            //  wss 长连地址，返回多个不同集群的地址，默认使用第一个即可，用于生产环境请做好连接失败后切换集群的兜底逻辑
            "wss_link": [
                ""
            ]
        },
        //  主播信息
        "anchor_info": {
            // 主播房间号
            "room_id": 0,
            // 主播昵称
            "uname": "",
            // 主播头像
            "uface": "",
            // 主播uid
            "uid": 0
            //用户唯一标识
            "open_id":"39b8fedb-60a5-4e29-ac75-b16955f7e632",
            //开发者维度下用户唯一标识
            "union_id":"U_ed2cbbb8-2c8f-4fcd-bc47-b62f0e1fca75",
        }
    }
}
```

## 项目关闭

- 接口描述：项目关闭时需要主动调用此接口，使用对应项目Id及项目开启时返回的game_id作为唯一标识，调用后会同步下线互动道具等内容，项目关闭后才能进行下一场次互动。
- 接口地址：/v2/app/end
- 方法：POST
- 请求头：需要
- 请求参数：

| 参数名 | 必选 | 类型 | 描述 |
| --- | --- | --- | --- |
| app_id | 是 | integer(13位长度的数值，注意不要用普通int，会溢出的) | 项目id |
| game_id | 是 | string | 场次id |

- 响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

## 项目心跳

**接口描述**：
项目开启后，推荐持续间隔20秒调用一次该接口。
互动玩法超过60秒，互动插件和互动工具超过180s未收到项目心跳，会自动关闭当前场次（game_id），同时消息长连将停止推送消息，并且将道具相关功能下线，以确保下一场次项目正常运行。

注意：
1、互动玩法一个直播间只能同时启动一个，并且如果玩法没正常调用end结束，需要间隔一分钟以上才能启动第二个。
2、互动插件一个直播间可以启动多个，单个插件最多建立5个连接，单个插件的第6个连接API会提示超过数量的错误提醒并连接失败。

**接口地址**：/v2/app/heartbeat
**方法**：POST
**请求参数**：

| 参数名 | 必选 | 类型 | 描述 |
| --- | --- | --- | --- |
| game_id | 是 | string | 场次id |

**响应**：

```json
{
    "code": 0,
    "message": "ok",
    "data": {}
}
```

## 项目批量心跳

**接口描述**：为上面项目心跳的批量请求版本

注意：
1、互动玩法一个直播间只能同时启动一个，并且如果玩法没正常调用end结束，需要间隔一分钟以上才能启动第二个。
2、互动插件一个直播间可以启动多个，每个插件最多建立5个连接，单个插件的第6个连接API会提示超过数量的错误提醒并连接失败。

**接口地址**：/v2/app/batchHeartbeat
**方法**：POST
**请求头**：需要
**请求参数**：

| 参数名 | 必选 | 类型 | 描述 |
| --- | --- | --- | --- |
| game_ids | 是 | []string | 场次id(单次请求game_id数量要小于200条) |

**响应**：

```json
{
    "code": 0,
    "message": "ok",
    "data": {
        //  心跳失败的id
        "failed_game_ids": [
            ""
        ]
    }
}
```

## 官方API常见问题

#### 1. 官方API特性

- 更安全
  使用主播身份Code码进行互动玩法、H5插件开启，避免因为房间号错误引发的安全问题。
- 更便捷
  使用官方API进行互动玩法、H5插件、直播工具开启，可直接返回当前房间长连WSS地址，无需请求长连API(`/v1/common/websocketInfo`)获取长连地址。

#### 2. 是否影响互动玩法API使用

技术上会继续支持互动玩法API，新接入开发者优先使用官方API，互动玩法API将于6月15日逐步停止支持。

#### 3. 心跳说明

- 长连心跳
  长连心跳机制是定时发送一个自定义的结构体（心跳包）。服务端收到客户端的心跳包会回复客户端，如果服务端30s内没有收到连续的心跳包，则主动断开连接。这种机制是开发者与平台的双向保活探测，以确保连接的有效性。
- 项目心跳
  项目心跳是一种兜底保护机制，避免因项目异常退出未调用项目关闭（`v2/app/end`）导致的道具无法下线、其他项目无法开启等异常情况。项目开启后，需要持续间隔20秒调用一次项目心跳，超过180秒未收到项目心跳，开放平台会自动关闭当前游戏，同时将道具等功能同步下线，以确保下一场次项目正常运行。

#### 4. 直播姬传参启动

- 直播姬启动时会通过启动参数传递房间号和身份码给到应用程序，互动玩法在实现的时候应该注意接收并处理改参数
- 直播姬启动互动玩法传参例

```
start.exe -room_id=XXX  code=XXXX
```
